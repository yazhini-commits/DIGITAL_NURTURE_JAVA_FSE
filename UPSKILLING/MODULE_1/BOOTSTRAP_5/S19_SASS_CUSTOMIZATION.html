Bootstrap Sass Customization

This page describes how to customize Bootstrap with Sass.

Exercise 19.1: Use npm to install Bootstrap and Sass, then compile from the source files.

Exercise 19.2: Customize _variables.scss to change $primary and $border-radius, then rebuild Bootstrap. 

// Example Sass overrides
$primary: #0056b3;
$border-radius: 1.25rem;
@import "bootstrap/scss/bootstrap";
